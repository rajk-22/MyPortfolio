RAJA KUMARI — PORTFOLIO WEBSITE
================================

FILES
- index.html: website content and page structure
- style.css: responsive corporate styling
- script.js: mobile navigation and scroll reveal interactions
- profile.jpg: add your own portrait photo using this exact filename

HOW TO PREVIEW
1. Extract the ZIP file.
2. Open the folder in VS Code.
3. Add your portrait image and name it profile.jpg.
4. Open index.html in a browser, or use the VS Code Live Server extension.

BEFORE PUBLISHING — PERSONALISE THESE ITEMS
1. In index.html, replace every instance of your.email@example.com with your real email.
2. Replace the LinkedIn placeholder URL and label with your LinkedIn profile.
3. Replace the GitHub placeholder URL and label with your GitHub profile.
4. Review the skills and project descriptions to ensure they match what you have personally completed.
5. Add project links if you have public demos or repositories.

NOTES
- The profile photo area displays an initials placeholder until profile.jpg is added.
- No made-up phone number, email address, LinkedIn URL, GitHub URL or project demo has been inserted.
- This is a static HTML/CSS/JavaScript website. It does not require a backend.
